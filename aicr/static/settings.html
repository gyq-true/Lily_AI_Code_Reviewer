使用说明
  • 推荐在项目根目录创建 .env（参考 .env.example），优先级高于本页设置。
  • Ollama 为本地模型，无需 API Key，先执行 ollama pull qwen2.5-coder:7b。
  • CLI 用法：aicr review 目录/文件、aicr diff 仓库路径 --staged。
  • 每次审查的完整请求与报告都会落盘到 data/runs/<run_id>/（meta.json / trace.jsonl / report.json）。
