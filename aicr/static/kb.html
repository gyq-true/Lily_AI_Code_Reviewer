使用说明
  • 先在 设置 中开启「启用知识库」并配置向量库与 embedding 模型。
  • 推荐摄入项目根目录：会收集 README.md、docs/、*.md 及源码文件。
  • embedding 使用本地 sentence-transformers，首次运行会下载模型（约 470MB）。
  • 向量库默认本地内嵌（无需 Docker）；也可在设置中填写 Qdrant 服务地址接入 Docker / Qdrant Cloud。
